# 🚀 Nexus Platform
> Investor & Entrepreneur Collaboration Platform

## 🌐 Live Demo
**Frontend:** https://nexus-3i7a.vercel.app

## 📹 Demo Video
[Click here to watch demo](#) <!-- video link  -->

## ✅ Features
- 🔐 JWT Authentication + 2FA OTP
- 👥 Role-based (Investor / Entrepreneur)
- 📅 Meeting Scheduling + Calendar
- 🎥 Video Calling (WebRTC + Socket.IO)
- 📄 Document Upload + E-Signature
- 💳 Payment System (Stripe)
- 🔒 Security (Helmet, Rate Limiting, bcrypt)

## 🛠️ Tech Stack
| Frontend | Backend | Database | Services |
|----------|---------|----------|----------|
| React + TypeScript | Node.js + Express | MongoDB Atlas | Cloudinary |
| Tailwind CSS | Socket.IO | Mongoose | Stripe |
| React Router | JWT Auth | | Nodemailer |
